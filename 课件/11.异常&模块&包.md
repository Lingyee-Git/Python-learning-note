问题
我定义了一个包和模块：
```python
print("module1")

def info_print1():
    print("my_module1")
```
调用：
```python
from mypackage import *
my_module1.info_print1()
```
我想问，为什么我只调用了info_print()函数，结果还是显示
```
module1
my_module1
```
那我专门调用这个功能干什么呢？

回答
你遇到的是 Python 中一个很重要的概念：模块导入时的执行机制。
你现在的代码大概是这样的：
`mypackage` 目录下：
```
mypackage/
├── __init__.py
└── my_module1.py
```
`my_module1.py`：
```
print("module1")def info_print1():    print("my_module1")
```
主程序：
```
from mypackage import *my_module1.info_print1()
```
运行结果：
```
module1
my_module1
```
我们拆开来看。
### 1.为什么会输出 `module1`？
因为 Python 在导入模块时，会先执行模块中所有没有缩进在函数、类等定义内部的代码。
当你执行：
```
from mypackage import *
```
Python 会导入包中允许被 `*` 导入的名称。
如果你的 `__init__.py` 中写了：
```
from . import my_module1
```
那么导入包时，就会进一步导入 `my_module1` 模块。
此时，模块中的：
```
print("module1")
```
就会立即执行。
注意：这行代码并不在函数内部，所以它不是等到你调用函数时才执行的。
### 2. 为什么调用函数又输出 `my_module1`？
因为这一步：
```
my_module1.info_print1()
```
才是真正调用函数。
所以输出分成两部分：

| 执行阶段 | 执行内容               | 输出         |
| ---- | ------------------ | ---------- |
| 导入模块 | `print("module1")` | module1    |
| 调用函数 | `info_print1()`    | my_module1 |

### 3. 那么专门定义函数有什么意义？
这是你真正想问的问题。
假设你有一个模块：
```
print("程序开始运行")def add(a, b):    return a + bdef subtract(a, b):    return a - bdef multiply(a, b):    return a * b
```
导入这个模块时，只会执行顶层的 `print()`，而不会自动执行三个函数。
之后你可以根据需要选择：
```
import my_moduleprint(my_module.add(1, 2))
```
或者：
```
print(my_module.multiply(3, 4))
```
只有被调用的函数才会执行。
函数的意义就在于：将一段代码封装起来，需要的时候再执行，而不是每次导入模块就把所有功能都运行一遍。
### 4. 一个值得记住的知识点
你可以把模块中的代码分为两类：
- 顶层代码：导入模块时执行。
- 函数和类内部的代码：定义时不会执行，只有调用函数或创建对象并触发相应逻辑时才执行。
所以，实际编写模块时，通常会把功能封装在函数或类中，尽量避免在模块顶层写大量会直接执行的代码。
给你留一个小练习：
如果 `my_module1.py` 改成这样：
```
print("module1")def info_print1():    print("my_module1")def info_print2():    print("my_module2")
```
主程序仍然是：
```
from mypackage import *my_module1.info_print1()
```
你觉得会输出几行？`info_print2()` 会不会执行？
这个问题想明白，你就真正理解模块导入和函数调用的区别了。
