# 闭包与装饰器

## 1.闭包
```python
# 1.闭包
# 1.1 定义：函数嵌套的前提下，内部函数使用了外部函数的变量并且外部函数返回了内部函数，我们把这个使用外部函数变量的内部函数称为闭包。
# 1.2 作用：保存外部函数内的变量
# 1.3 构成条件：(1)函数嵌套
#              (2)内部函数使用了外部函数的变量或参数
#              (3)外部函数返回了内部函数

# 1.4 构成闭包
def func_out():
    x = 100
    def func_inner(y):
        result = x + y
        print(result)
    return func_inner   # 不加括号，加了表示运行该函数

# 1.5 使用闭包
result = func_out() # 即result = func_inner
result(1)   # 101

# 1.6 应用实例
# 需求：根据配置信息使用闭包实现不同人的对话信息
# 实现对话：
# 张三：到北京了吗？ 李四：已经到了，放心吧。
# 实现步骤：(1)定义外部函数 接收不同的配置信息参数（人名）
#          (2)定义内部函数 接收对话信息参数
#          (3)在内部参数里面把配置信息和对话信息进行拼接输出
def func_out(name):
    def func_inner(message):
        result = f"{name}:{message}"
        print(result)
    return func_inner

zhans = func_out("张三")
lis = func_out("李四")

zhans("到北京了吗？")
lis("已经到了，放心吧。")

# 思考：
# 使用闭包比普通函数好在哪里？
# 如果使用普通函数，每次输入信息都需要重复输入"张三""李四"，而使用闭包只需要每次输入他们的话。
# 那为什么不写成两个分属于张三和李四的函数呢？
# 两个人还好，如果是两百个呢？难道要写两百个函数吗？使用闭包，只需定义一次外部函数，就可以创建任意多个具有不同配置信息的闭包。
# 所以，闭包的作用：保存外部函数的变量，使内部函数在外部函数执行结束后，仍然能够访问这些变量。在本例中，保存的变量是 name
```
