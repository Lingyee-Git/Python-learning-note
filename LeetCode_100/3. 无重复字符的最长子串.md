给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

**示例 1:**

**输入:** s = "abcabcbb"**输出:** 3 
**解释:** 因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

**示例 2:**

**输入:** s = "bbbbb"**输出:** 1
**解释:** 因为无重复字符的最长子串是 `"b"`，所以其长度为 1。

**示例 3:**

**输入:** s = "pwwkew"**输出:** 3
**解释:** 因为无重复字符的最长子串是 `"wke"`，所以其长度为 3。
     请注意，你的答案必须是 **子串** 的长度，`"pwke"` 是一个_子序列，_不是子串。

## 暴力解法（超时）
```python
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        """
        :type s: str
        :rtype: int
        """
        n = len(s)
        result = []

        for i in range(n):
            lst = []
            lst.append(s[i])

            for j in range(i + 1, n):
                if s[j] not in lst:
                    lst.append(s[j])
                else:
                    break
            
            result.append(len(lst))
        
        return max(result)
```

## 滑动窗口

**思路**
滑动窗口，顾名思义，用左右两个边框来限定窗口。
左边框从左往右遍历，右边框也从起始点开始向右逐个检查，无重复则将该字符加入到哈希集合中，直到遇到重复。
遇到重复后，不添加新字符，先记录下此时集合中的字符数，再将左边框往右移一格，并且将移出窗口的字符删除。由于我们的右边框刚才已经保证，当前窗口没有重复，所以不需要右边框从头遍历（区别于暴力枚举），只需要右边框继续向右读取，重复以上过程。

```python
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        """
        :type s: str
        :rtype: int
        """
        # 哈希集合，记录每个字符是否出现过
        occ = set()
        n = len(s)
        # 右指针，初始值为-1
        rk, ans = -1, 0
        for i in range(n):
            if i != 0:
                # 左指针向右移动一格，移除一个字符
                occ.remove(s[i - 1])
            while rk + 1 < n and s[rk + 1] not in occ:
                # 不断地移动右指针
                occ.add(s[rk + 1])
                rk += 1
            # 第 i 到 rk 个字符是一个极长的无重复字符子串
            ans = max(ans, rk - i + 1)
        return ans
```
