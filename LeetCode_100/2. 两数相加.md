请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

### 链表（Linked List）

#### 1. 基本概念

链表是一种线性数据结构，由多个节点（Node）组成。

每个节点包含两部分：

- `val`：存储当前节点的数据。
    
- `next`：存储下一个节点的引用（指针）。
    

链表通过节点之间的引用连接，而不是通过连续的内存空间存储元素。

```
head
 ↓
[2 | next] → [4 | next] → [3 | None]
```

#### 2. 主要特点

- 无连续存储要求：节点在内存中不一定连续。
    
- 无索引：不能像列表一样通过 `list[i]` 直接访问元素。
    
- 顺序访问：需要从头节点开始，沿着 `next` 逐个访问。
    
- 动态长度：可以根据需要增加或删除节点。
    
- 引用连接：通过 `next` 建立节点之间的联系。
    

#### 3. 优势与局限

| 优势        | 局限         |
| --------- | ---------- |
| 动态分配空间    | 不支持随机访问    |
| 插入、删除节点方便 | 查找元素需要遍历   |
| 不要求内存连续   | 需要额外空间存储引用 |

#### 4. 常见应用

- 栈、队列等数据结构的实现。
    
- 操作系统中的进程管理。
    
- 图结构的邻接表表示。
    
- 需要频繁插入、删除元素的场景。
    

#### 5. 基础语法（Python）

（1）定义节点类

```python
class ListNode(object):
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

（2）创建节点

```python
a = ListNode(2)
b = ListNode(4)
c = ListNode(3)
```

（3）连接节点

```python
a.next = b
b.next = c
```

（4）获取节点值

```python
a.val       # 2
a.next.val  # 4
```

（5）遍历链表

```python
cur = head

while cur is not None:
    print(cur.val)
    cur = cur.next
```

（6）创建新链表（虚拟头节点法）

```python
dummy = ListNode(0)
cur = dummy

cur.next = ListNode(2)
cur = cur.next

cur.next = ListNode(4)
cur = cur.next

return dummy.next
```

#### 6. 常用变量与概念

|名称|含义|
|---|---|
|`head`|链表头节点（入口）|
|`cur`|当前遍历节点|
|`next`|下一个节点的引用|
|`dummy`|虚拟头节点，方便构建新链表|
|`None`|链表结束标志|
|`cur = cur.next`|指针后移一个节点|

补充： `cur = head` 是让 `cur` 引用头节点；移动 `cur` 不会改变 `head` 的位置，也不会改变原链表的连接关系。

## 解法1

思路：分别依次获取节点值→计算原数→加和→创建新链表

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def addTwoNumbers(self, l1, l2):
        """
        :type l1: Optional[ListNode]
        :type l2: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        cur1 = l1
        cur2 = l2

        num1 = 0
        i = 0
        while cur1 is not None:
            num1 += cur1.val * (10**i)
            i += 1
            cur1 = cur1.next
        
        num2 = 0
        j = 0
        while cur2 is not None:
            num2 += cur2.val * (10**j)
            j += 1
            cur2 = cur2.next
        
        add_result = num1 + num2

        dummy = ListNode(0)
        cur = dummy

        for i in str(add_result)[::-1]:
            cur.next = ListNode(int(i))
            cur = cur.next
        
        return dummy.next
```

## 解法2

思路：由于输入的两个链表都是逆序存储数字的位数的，因此两个链表中同一位置的数字可以直接相加。我们同时遍历两个链表，逐位计算它们的和，并与当前位置的进位值相加。
如果两个链表的长度不同，则可以认为长度短的链表的后面有若干个 0 。
此外，如果链表遍历结束后，进位>0，还需要在答案链表的后面附加一个节点。

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def addTwoNumbers(self, l1, l2):
        """
        :type l1: Optional[ListNode]
        :type l2: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        cur1 = l1
        cur2 = l2

        # 初始化进位数
        total = cur1.val + cur2.val
        i = total // 10
        
        # 创建结果链表第一个节点
        l3 = ListNode((cur1.val + cur2.val) % 10)
        cur3 = l3

        # 处理一般情况
        while cur1.next and cur2.next:
            total = cur1.next.val + cur2.next.val + i
            cur3.next = ListNode(total % 10)
            # i更新
            i = total // 10
            # cur更新
            cur1 = cur1.next
            cur2 = cur2.next
            cur3 = cur3.next
        
        # 处理l1、l2位数不相等的情况
        # 1.l1更长
        while cur1.next:
            total = cur1.next.val + i
            cur3.next = ListNode(total % 10)
            # i更新
            i = total // 10
            # cur更新
            cur1 = cur1.next
            cur3 = cur3.next
        
        # 2.l2更长
        while cur2.next:
            total = cur2.next.val + i
            cur3.next = ListNode(total % 10)
            # i更新
            i = total // 10
            # cur更新
            cur2 = cur2.next
            cur3 = cur3.next
        
        # 处理最高位数运算的进位情况
        if i == 1:
            cur3.next = ListNode(1)
        
        return l3
```

## 解法3

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def addTwoNumbers(self, l1, l2):
        """
        :type l1: Optional[ListNode]
        :type l2: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        dummy = ListNode(-1)
        cur = dummy
        carry = 0
        while l1 or l2 or carry:
            v1 = l1.val if l1 else 0
            v2 = l2.val if l2 else 0
            s = v1 + v2 + carry
            cur.next = ListNode(s % 10)
            cur = cur.next
            carry = s // 10
            l1 = l1.next if l1 else None
            l2 = l2.next if l2 else None
        return dummy.next
```

### 问题：
1. 链表的理解：对于已有链表，我规定的l1、l2等等变量都是指向该链表第一个节点而不是说包含这个节点，对于列表、字典等亦然；又因为链表是可修改对象，因此我采用cur3作为指针修改链表内容后，返回l3，也指向的是这个链表，也是修改后的，思路类似[可变类型与不可变类型](obsidian://open?vault=%E8%AF%BE%E4%BB%B6&file=10.%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2%26%E6%B7%B1%E6%B5%85%E6%8B%B7%E8%B4%9D%26%E9%80%92%E5%BD%92%26%E5%BC%95%E7%94%A8)；链表不能索引，只能指定指针，指向链表的“头“，然后依次使用next访问下去
2. python是从上至下执行的：比如后面的处理特殊情况的代码生效时，必定意味着前面的通用代码已经执行完毕，cur1、cur2、cur3等都已经更新，而不是一定要用if语句严格约束执行条件，感受这个过程
3. **切片**：`序列[start:stop:step]`，故`lis[::2]`意思是不指定开始结尾，步长为2取值，也就是从头到尾步长为2取值；`lis[::1]`意思是生成一个与原对象一模一样的副本；`lis[::-1]`意思是生成一个原对象的倒序副本
4. `while l1 or l2 or carry`：此处`carry`为0也可终止循环，因为0的布尔值是`False`，类似还有`None`、`""`、`0.0`
